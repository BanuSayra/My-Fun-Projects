
# 🎯 Asra's Number Guessing Game

🔗 **Live App:** https://my-fun-projects-asra-number-game.streamlit.app/

---

## 📌 Project Overview

This is a fun and interactive **Number Guessing Game** built using **Python and Streamlit**.

The game challenges users to guess a randomly generated number between **1 and 100** within a limited number of attempts.

---

## 🚀 Features

* 🎮 Interactive gameplay with Streamlit UI
* 🔢 Random number generation
* 🎯 Maximum 10 attempts to guess correctly
* 📉 Hints provided (Too High / Too Low)
* 🎉 Success message with attempt count
* 🔄 Restart option to play again
* 🎈 Bonus celebration for excellent performance

---

## 🧠 Game Logic

* A random number is generated using Python’s `randint()`
* User inputs a guess through the UI
* The app provides feedback:

  * "Too High" → guess lower
  * "Too Low" → guess higher
* Game ends when:

  * User guesses correctly ✅
  * OR exceeds 10 attempts ❌
